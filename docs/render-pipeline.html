One representation: BC7 RGBA, already display-encoded; no sRGB sampling decode and no alternate cache codec. Unsupported capabilities report cache unavailability while live rendering stays available. Source video and full-quality export retain their legitimate media codecs.

Ordered versus latest-winsPreparing the next playback frame cannot stale its predecessor. Seek, edit, reverse, loop and closure reject obsolete publication independently per viewer.
Bytes before allocationShared allocator reservations and eligible eviction cover active work. RAM, compressed residency, staging, retained inputs, metadata and disk remain bounded; active resources stay pinned.
Independent recordsReplacing a frame preserves its neighbors. Corrupt or incomplete records are rejected; pack reclamation touches cache-owned storage only. Lossy display data never supplies export or working-space picks.
Buffer / copy details and source map

Buffer and synchronization boundaries

Working images: four channels use packed RGBA32F; other channel counts use scalar R32F planes. The small scene-linear intermediate store is separate from the compressed playback cache. Data/Raw sources retain their declared interpretation.

Effects: compatible dispatches/barriers are batched; Blur uses a scratch image for its separable passes. Region/output crops may add GPU writes. There is no routine per-node CPU download.

Decode: hardware keeps pixels on-device; software paths copy CPU pixels to mapped staging, then upload. Decode/conversion convenience paths wait for GPU completion.

Presentation: one compute pass writes shared RGBA8 directly. BC7 decompression is texture sampling on the execution device, not a float image reconstruction; Qt imports the shared surface and waits through the external semaphore. Overlays are not cached.

Lifetime: images, blocks, staging and descriptors stay retained until their actual GPU use completes. Queue policy belongs to the existing scheduler; submission serialization stays with the device. Cancellation changes publication eligibility, not completion ownership.

Scope: viewer playback only. Compressed display images never become scene-linear effect inputs or full-quality export sources. Working-space pixel picking and explicit delivery use separate evaluation paths.
